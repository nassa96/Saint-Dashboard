Exchange venues

Connect the exchange your money is on. Coinbase uses the current CDP Secret API Key contract: key name + ECDSA private key + portfolio UUID. Withdrawals/transfers must remain disabled.

⚡ Live trading

Paper mode is safe and default. Arming sends real orders with real money on your primary venue. Requires connected keys + the exact confirmation phrase. Disarm is instant.

On-chain wallet (server-side execution keys)

Self-custody swaps (Solana / EVM). Quotes are always read-only; real swaps stay hard-gated. Tron balance reads work; Tron swaps are intentionally disabled (see docs/TRON_SWAP.md). HyperLiquid is monitor-only (perps, not spot).
A wallet private key controls all your funds, so — unlike exchange keys — it is never accepted through this web form. Set it once in .env on your server (SOLANA_PRIVATE_KEY, EVM_PRIVATE_KEY, TRON_PRIVATE_KEY, or HYPERLIQUID_API_PRIVATE_KEY) and restart. This page shows its status.

🔌 Connect a wallet from your browser (read-only)

This asks your wallet extension for its public address only — never a seed phrase, never a private key, never a signature. No funds can move from this. It's the safest possible way to just look at a wallet's balance on the dashboard.

Getting exchange API keys

Coinbase:
  1. Coinbase Developer Platform → create a Secret API Key for Advanced Trade.
  2. Use ECDSA and grant View + Trade. Keep Transfer/Withdrawals OFF.
  3. Copy the API key name, the full EC private key (PEM), and the portfolio UUID.
  4. Do not paste a Coinbase Commerce credential or legacy passphrase.
Kraken / Binance.US: create an API key with trade + query permissions, withdrawals off, then paste key + secret (no passphrase).
