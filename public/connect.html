🔒 Safety: only paste API keys with withdrawals DISABLED (trade + view only). Keys are saved to data/credentials.json on your server (git-ignored) and are used read-only until you deliberately arm live trading. Set DASHBOARD_PASSWORD before exposing this page to any network.

Exchange venues

Connect the exchange your money is on. On Coinbase, use Advanced Trade keys (0.60% fee) — not the one-tap app.

On-chain wallet

Self-custody swaps (Solana / EVM). Quotes are always read-only; real swaps stay hard-gated.
A wallet private key controls all your funds, so — unlike exchange keys — it is never accepted through this web form. Set it once in .env on your server (SOLANA_PRIVATE_KEY or EVM_PRIVATE_KEY) and restart. This page shows its status.

Getting exchange API keys

Coinbase:
  1. Coinbase → Settings → API (or Advanced Trade API).
  2. Create a key with View + Trade permissions. Do NOT enable Transfer/Withdraw.
  3. IP-allowlist your server if offered. Copy the API key, secret, and passphrase here.
Kraken / Binance.US: create an API key with trade + query permissions, withdrawals off, then paste key + secret (no passphrase).
